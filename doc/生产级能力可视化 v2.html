03

落地优先级

按上线节奏拆分为三个层级，同一层级内按工程量排序。

3 层级 / 19 项
P0 上线前必须 08 项
  1. HTTPS / TLS、安全响应头
  2. 密码 BCrypt、敏感字段 AES 加密与脱敏
  3. 接口鉴权与越权校验（RBAC）
  4. 操作日志与登录日志、日志脱敏
  5. 支付回调 / 退款 / 下单幂等
  6. 登录与导出接口限流
  7. 数据库定期备份与恢复演练
  8. 配置与密钥外置，禁止提交仓库
P1 随业务量补齐 06 项
  1. Redis 缓存（字典、权限、线路、看板）
  2. Redisson 分布式锁（库存、领券、定时任务）
  3. 慢 SQL 治理、索引优化、连接池调优
  4. Prometheus + Grafana 监控与告警
  5. 优雅停机、健康检查、CI/CD
  6. 缓存穿透 / 击穿 / 雪崩治理
P2 规模化演进 05 项
  1. 消息队列（订单超时、异步通知、日志）
  2. 链路追踪（SkyWalking）
  3. 读写分离、分库分表
  4. 多级缓存与热点探测
  5. 多活与容灾
